# hermes-web-themes — Hermes Rules

## Mandatory skill

Always load `bchop-repository-lifecycle` before any code, config, or documentation change in this repo.

## Quick checks

- Never commit to `main`. Branch + PR always.
- When pushing new commits to an existing PR, update the PR body.
- **Security: never commit secrets. Keys in `.env` only. Secret scan before every commit.**
- Update `BUILDLOG.md` after meaningful checkpoints.
- After merge: sync main, delete task branches, prune.
