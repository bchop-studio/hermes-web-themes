# Security Policy

## Supported version

The latest commit on `main` is supported.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/bchop-studio/hermes-web-themes/security/advisories/new) for security-sensitive reports.

Do not open a public issue for a suspected vulnerability. Include the affected theme or script, reproduction steps, impact, and any suggested fix. Reports will be reviewed before details are made public.

## Scope

Security reports may cover the theme YAML files, converter and validation scripts, installation instructions, dependency configuration, or repository automation.
